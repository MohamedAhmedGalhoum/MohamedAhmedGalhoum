### 💻 Featured Projects

#### 🧵 Threadly — Reddit Clone

> A production-ready social platform built with modern full-stack technologies.

**Tech Stack:**

`Next.js` `React` `TypeScript` `Prisma` `PostgreSQL` `Neon Auth` `Tailwind CSS`

**Highlights:**

* 🔥 Designed a feed-ranking engine supporting **Hot / Top / New**
* ⚡ Improved tag lookup complexity from **O(N × M) → O(N + M)**
* 📈 Improved feed retrieval by approximately **50%**
* 🏗️ Applied **Strategy & Repository design patterns**
* 🗄️ Designed normalized relational models for Posts, Tags, Votes, and Comments
* 🔐 Integrated secure authentication with Neon Auth
* 🧱 Built reusable UI components with React, Tailwind CSS and shadcn/ui
